Backup & Restore

All your saved templates, favorites, archive, presets and order live only in this browser on this device. If browser data ever gets cleared, your customizations go with it.

Strongly recommended: download a backup file every now and then and stash a copy somewhere offline — Google Drive, email it to yourself, an external hard drive, whatever. If anything ever goes sideways, you can restore everything in one click.

How to use these templates

Click each section below for setup steps. Most templates are print-ready — just click Print in any template’s toolbar to save as PDF or send to a printer.

Editing, exporting & saving (Edit / Export / Save As)
  • Edit — on any template, click Edit in the top-right toolbar. The page gets a dashed blue outline and every text element becomes editable. Click any text and just type. Click ✓ Done editing to exit.
  • Export ▾ — opens a menu with four options:
    • Print — sends to your browser's print dialog. Use this for paper printing or to save a system PDF.
    • PDF — saves a real PDF in the page's exact dimensions (envelope, card, letter, etc.).
    • Image (.png) — saves a 2× resolution PNG. Multi-sheet templates export as multiple files.
    • HTML (.html) — saves a self-contained HTML file you can re-open, email, or archive.
  • Save As — saves the current filled-in template into your Your Library section on the index. All filled content, the signer name, and the recipient address are preserved in the saved copy. Keeps the original blank template untouched.
Signatures (gallery, auto-fill, wet sign)

The Signatures panel on this page holds a labeled gallery of signatures. The active one (highlighted chip) auto-fills every letter template. You can store as many as you like — one per person, or formal vs. casual versions of your own.

  1. Sign your name in dark ink on a clean piece of white paper. Take a photo or scan it and save as JPG or PNG.
  2. In the Signatures panel, click + Add signature and pick the file. Whitespace is auto-cropped.
  3. Type a label when prompted — e.g. Joshua, David Mitnick, or Formal. A chip appears in the gallery.
  4. Click any chip to make it the active signature. Open any letter template — it appears on the signoff line automatically.
  5. To print with a blank signature line for a physical (wet) signature, click Leave blank — the first chip in the gallery.
  6. To remove a signature, click the × on its chip.
Signatures are tied to the currently signed-in user. Each user manages their own gallery. JPGs with white backgrounds work fine — a CSS trick blends white pixels with the page so they won't print as a white box.
Nudge & resize: on any letter, click Edit in the top toolbar, then drag the signature to reposition it. A small blue handle at the bottom-right corner resizes it (aspect ratio locked). Position and size save automatically per template.
Want a transparent background? Use a free tool like remove.bg, save as PNG, then upload. Best for signatures on non-white backgrounds.
Backup & Restore
  • The Backup & Restore panel above the instructions lets you download a single JSON file containing every customization on this browser — all users' favorites, archives, libraries, presets, and order preferences.
  • Strongly recommended: click Download backup after any major reorganization, and email the file to yourself or drop it in Google Drive. If browser data ever gets cleared, you can restore everything in one click.
  • The file is plain text — readable in any text editor. Safe to keep multiple versions.
  • Restoring overwrites current data, so back up first if you're not sure.
Multiple users (sign-in)
  • Visit users.html (or click ↻ Switch user at the top of the page) to pick or add accounts.
  • Each user has their own favorites, archive, library, presets, and section/template order. Switching users doesn't disturb anyone else's data.
  • Built-in templates and any edits made to the source HTML files are shared by everyone — that's the point. Update once, every user sees it.
  • Removing a user (the × on their card) wipes their saved data permanently.
  • This isn't real authentication — no password, no central account. Anyone using this browser can pick any name. Don't store sensitive info under another person's account.
If you want each user to keep their data when switching devices, you'd need to host this on a real URL (e.g. GitHub Pages) and have everyone use the same bookmarked link. Localstorage is still per-browser, but a stable URL makes it easy to know where to come back to.
Organizing your templates
  • Star (★) — hover any card, click the ★ button to mark it as a favorite. Starred templates move to a ★ Favorites section at the top of the page. Click again to unstar.
  • Archive (⌫) — hover any card, click the ⌫ button to move it to the archive. It disappears from the main page but isn't deleted. Visit Archive from the link at the top of the page to restore or permanently delete.
  • Delete (×) — only appears on your saved Library items. Permanently removes a custom template.
  • Drag to reorder — drag any template card around within its section to change the order. Drag the section title (e.g. "STATIONERY") up or down to reorder whole sections. Your order is remembered.
  • Your Library — at the bottom of the page. Holds copies of templates you've filled out and saved with the Save As button on individual templates.
  • Reset Everything — the red button at the very bottom of the page. Clears all your customizations (stars, archive, library, presets, order) and restores the original layout. Doesn't delete any template files.
Setup panel — Tenants, Vendors & Sender

The Setup button in any template toolbar opens a panel with three tabs: Sender, Tenants, and Vendors. Use it to fill the recipient address block, body field references, and the signoff — without typing anything manually.

Sender tab

  • Pick which owner LLC appears in the signoff (e.g. LPR Management, LLC vs. a specific property LLC). Import your owner list from a Buildium CSV or add manually.
  • Toggle Include signer name to show or hide the employee name and title below the signature.
  • Toggle Use office contact to replace the signer's direct phone/email with the main office line.
  • Click Apply to Template to update the signoff.

Tenants tab

  1. First time: click ↑ Import CSV and pick your Buildium tenant export. The list is saved in your browser for future visits.
  2. Search or scroll to find a tenant, then click their row.
  3. Review or edit any field — edits are saved per-tenant and survive future CSV re-imports unless Buildium now matches the edited value.
  4. Apply as Recipient — fills the mailing address block at the top of the document and any tenant body-reference fields (name, address mentioned in the letter body).
  5. Body fields only — fills only the body references, leaving the recipient address block untouched. Use this when the letter is addressed to a vendor but references a tenant's property.

Vendors tab

  1. Click ↑ Import CSV and pick your Buildium vendor export.
  2. Select a vendor from the list. Edit any field directly in the panel — same override system as tenants.
  3. Apply as Recipient — fills the mailing address block with the vendor's name and address.
  4. Body fields only — fills only vendor body references, leaving the recipient block for a tenant.
Cross-party letters: writing to a vendor about a tenant's property? Use Vendor → Apply as Recipient for the address block, then Tenant → Body fields only for the property references in the body. The two are fully independent.
Unfilled field warning: if you Export or Save As while some field types are still empty, a prompt tells you exactly which fields will print blank and lets you go back or continue anyway.
Insert fields while editing: click Edit first, then open Setup — an Insert Field sidebar appears. Click any field button to paste a field marker at your cursor, useful when building a new custom notice. Clear All Fields empties all filled spots in one click.
Address labels (P-touch, Brother QL-810W)
  1. Open Address Labels — P-touch from the Stationery section.
  2. Click Setup → Tenants tab → pick a tenant → click Apply as Recipient. The label preview updates with their name and address. Works for vendors too — use the Vendors tab.
  3. Click Download .lbt in the toolbar. A file named after the recipient is saved.
  4. Double-click the .lbt file — it opens in P-touch Editor (or Lite) with the address already populated.
  5. Make sure a DK-1201 standard address tape (29mm × 90mm) is loaded in your QL-810W, then click Print.
You can also click Edit on the label page and type directly into the preview to adjust the address before downloading.
Font: Labels use Arial — a standard Windows font that P-touch Editor reliably supports.
Large labels (DK-1202): The size toggle is visible but download is disabled until a DK-1202 template file is created. See the notice on the template page for how to enable it.
Certificate of Mailing (PS Form 3817)
  1. Get free blank PS Form 3817 slips from any USPS post office counter.
  2. Open Certificate of Mailing from the Stationery section. Click Setup and pick a tenant or vendor — the "To" address fills automatically. Or click Edit to type it manually.
  3. Calibrate once: click Print and print on plain paper first. Hold the printout behind a blank form to check alignment. Use the Up/Down and Left/Right sliders at the top of the template page to nudge the text until it lands on the form's lines. Calibration saves automatically.
  4. Feed a blank PS Form 3817 into your printer's manual/bypass tray. Try face-up first; flip it if text prints on the wrong side.
  5. Click Print in the toolbar. Set paper size to 5″ × 3″ in the print dialog (or select the manual feed tray if your printer auto-detects size).
  6. Bring the filled form to the post office. The postal worker stamps Postmark Here and returns it — that's your proof of mailing.
The From address (LPR Management, LLC) is pre-filled. Click Edit in the toolbar if you ever need to change it.
Editing for a specific employee
  1. Fill in the Customize for an employee form at the top of this page.
  2. Click any template card. The template opens with that employee’s name, title, phone, and email already filled in.
  3. To switch employees, change the values above and click another template — no need to refresh anything.
Signer options per letter: on any letter template, open Setup → Sender to change which LLC appears in the signoff, toggle the signer name on/off, or switch to the office contact line — without leaving the template.
Templates that respect the employee fields: Business Card, Letterheads, all notices, and Email Signature. Business Card — Company, Envelopes, Mailing Labels, and Letter Watermark are company-only and don’t change per employee.

You can also bookmark a template with an employee baked into the URL — e.g. Business Card.html?name=Jane%20Smith&title=Leasing%20Agent&phone=410.555.0123&email=jane@lasalleparkrealty.com

Business Cards (Personal & Company)
  1. Business Card — personal card for a specific employee. Fill in the employee form above first.
  2. Business Card — Company — office card with no name. Uses the main office phone, email, and address.
  3. Open the template. You’ll see front + back on screen.
  4. Click Print in the top toolbar. In the print dialog, choose Save as PDF, and set the paper size to US Letter with margins None.
  5. Send the PDF to a print shop (e.g. VistaPrint, Moo, or a local printer). Tell them: standard 3.5″×2″, two-sided, full-bleed.
Letterhead
  1. Open Letterhead. Use the Watermark toggle at the top to switch between the ghosted-logo version and a clean layout — your preference saves automatically.
  2. Fill in your employee details above, then replace the bracketed [Date], [Recipient], and body placeholders by clicking directly into the page (or use Setup → Tenants to auto-fill the recipient address).
  3. Click Print → Save as PDF (or print directly on letterhead paper).
For repeated use, save a PDF version per employee — then paste your letter content into Word/Google Docs and merge with the PDF letterhead, or just type into the HTML each time.
Email Signature
  1. Fill in employee details above.
  2. Open Email Signature. The signature appears in a sample email preview.
  3. Click inside the signature block, select all (⌘/Ctrl + A), and copy (⌘/Ctrl + C).
  4. Gmail: Settings (gear) → See all settings → General → Signature → Create new → paste → Save Changes.
  5. Outlook (web): Settings → Mail → Compose and reply → paste under “Email signature.”
  6. Apple Mail: Settings → Signatures → paste into the signature pane.
Logo image: the signature page has a toggle for Embed (base64) vs Hosted URL. Embed is the easiest — the logo travels inside the HTML, no setup needed. There’s also a Personal vs Company / Office toggle for a no-name version using the office contact info.
Envelopes
  1. Open Envelope and pick a style from the toggle bar at the top:
    • Standard — blue stripe · bold everyday mail with the brand blue side stripe.
    • Premium — ivory · refined warm-white layout. Includes an on-screen print-shop spec for bulk pre-printed runs.
    • Send address only · prints only the recipient block — for envelopes that already have a pre-printed or embossed return address.
  2. Click Setup → Tenants or Vendors tab → pick a recipient → Apply as Recipient. The address fills automatically. Or click Edit to type directly.
  3. Click Export → Print, set paper size to #10 Envelope (9.5″ × 4.125″), margins None.
Mailing Labels (Avery 5160)
  1. Buy Avery 5160 sheets (or compatible — 30 labels per sheet, 1″ × 2⅔″).
  2. Open Mailing Labels. The grid is pre-aligned to the Avery template.
  3. Click Print. In the print dialog: paper size US Letter, scaling 100% / Actual size, margins None. Run a test page on plain paper first.
Lease Cover Page
  1. Open Lease Cover Page.
  2. Click any bracketed field (Property, Landlord, Tenant) and type in the details.
  3. Print and staple/bind to the front of your lease document. Or save as PDF and merge with the lease in Acrobat / Preview.
Letter Watermark (Pre-printed paper)
  1. This is a background for pre-printing in bulk — your staff types letters into the body area after the paper comes back from the printer.
  2. Send the printed PDF to a print shop. Spec: US Letter, 24lb writing stock, full bleed, 4/0 CMYK.
  3. For one-off letters, use the Letterhead templates instead.
File formats — what to send to printers / use at home

Templates are HTML files in this project. To print or hand off to a printer, save each as PDF using your browser:

  • Open the template → click Print in the toolbar (or ⌘/Ctrl + P).
  • In the print dialog, set Destination = Save as PDF and click Save.

Business cards (commercial printer — e.g. VistaPrint, Moo, local shop):

  • Send the PDF. Tell them: 3.5″ × 2″, two-sided, no bleed required (artwork sits inside the safe area).
  • If they ask for bleed (some shops require it), let me know and I’ll produce a bleed version with 0.125″ added on each edge.
  • Some shops prefer print-ready PDF/X-1a or 300 DPI CMYK. PDFs exported from a browser are RGB — most consumer printers (VistaPrint, Moo) convert this automatically and the result is fine for a royal-blue + grayscale card. For a high-end stationer who wants exact PMS 287, ask me for a CMYK / spot-color version.

Envelopes — home printer:

  • Save as PDF, open in Preview / Adobe Reader, click Print.
  • Set paper size to #10 Envelope (9.5″ × 4.125″), scaling 100%, margins None.
  • Load envelopes in the printer’s manual-feed tray, flap closed, address-side up (check your printer’s envelope guide).
  • Run one test on plain paper first to confirm alignment before burning envelopes.

Envelopes — print shop bulk run:

  • Send the PDF. The default Envelope template includes an on-screen spec block (size, stock, ink, finish) to copy-paste into your order.

Letterhead — home printer:

  • Save as PDF → print on US Letter, 24lb writing stock, 100% scale, margins None.
  • For everyday letters you can also print the live HTML directly via the template’s Print button.

Mailing labels (Avery 5160): save as PDF, print on Avery 5160 sheets at 100% scale, margins None. Test on plain paper first.

Email signature: not a file at all — you copy the HTML directly out of the page and paste into Gmail/Outlook (see the Email Signature section above).

Quick reference: Browser HTML → Print → Save as PDF is the universal path. Send PDF to printers. Send HTML (copy-paste) into Gmail/Outlook.
