How to print: Use Fill Fields in the toolbar to pick a tenant — the label updates automatically. Then click Download .lbt. Double-click the downloaded file to open it in P-touch Editor Lite with the address already filled in. Make sure your QL-810W has a DK-1201 standard address tape loaded (29mm × 90mm), then click Print.

Font: Labels use Arial — a standard Windows font that P-touch Editor reliably supports.
